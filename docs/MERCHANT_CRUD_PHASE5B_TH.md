# Phase 5B - Merchant Real CRUD / หลังบ้านร้านค้าใช้งานจริง

รอบนี้ปรับ `/merchant/im-sticker` ให้ใกล้การใช้งานหน้าร้านจริงมากขึ้น ก่อนนำไปผูกกับ LINE OA / Rich Menu Pilot

## สิ่งที่เพิ่ม

- เพิ่มปุ่ม **เพิ่มสมาชิก** ในแท็บสมาชิก CRM
- เพิ่มฟอร์ม **บันทึกยอดซื้อ / แจกแต้ม** ให้เลือกสมาชิก กรอกยอดซื้อ และระบบคำนวณแต้มจาก `pointsRate` ของร้าน
- บันทึกรายการแจกแต้มเป็น transaction แบบ `earn` ลง Neon ผ่านระบบ sync เดิม
- ปรับ tier สมาชิกอัตโนมัติจาก lifetime points
- เพิ่มสถานะสำเร็จ/ผิดพลาดบนหน้า Merchant Dashboard
- เพิ่มการเปิด/ปิดการแสดงผลของรางวัล โดยไม่ต้องลบทิ้งถาวร
- เพิ่ม empty state เมื่อร้านยังไม่มีสมาชิกหรือของรางวัล
- ปรับระบบสร้างลิงก์แจกแต้มให้สร้างเมื่อกดปุ่มเท่านั้น เพื่อลดการสร้าง coupon ซ้ำโดยไม่ได้ตั้งใจ
- แก้ปุ่มคัดลอกลิงก์ในประวัติคูปองให้ชี้ไป `/customer/im-sticker?code=...`

## Flow ที่ควรทดสอบ

1. เปิด `/merchant/im-sticker`
2. กรอก Merchant PIN
3. ไปแท็บ **สมาชิก CRM**
4. กด **เพิ่มสมาชิก** แล้วเพิ่มสมาชิกใหม่
5. เลือกสมาชิก กรอกยอดซื้อ แล้วกด **บันทึก +X แต้ม**
6. ตรวจว่าแต้มสมาชิกเพิ่มขึ้น
7. ไปแท็บประวัติธุรกรรม ตรวจว่ามีรายการ `สะสมแต้ม`
8. เปิด `/api/db/health` ตรวจว่า `transactions` เพิ่มขึ้น
9. ไปแท็บ **ของรางวัลสะสมแต้ม** เพิ่มของรางวัลใหม่
10. ทดสอบปิด/เปิดการแสดงผลของรางวัล
11. ไปแท็บ **ลิงก์&คิวอาร์โค้ดแจกแต้ม** กดสร้างลิงก์ใหม่ แล้วคัดลอกลิงก์ไปเปิดที่ `/customer/im-sticker`

## หมายเหตุ

ระบบยังใช้ architecture แบบ Local Cache + Neon Sync อยู่ เพื่อให้แก้จาก mock-up เดิมได้เร็วและทดสอบง่าย ก่อนแยกเป็น API CRUD ราย action ในเฟสถัดไป
