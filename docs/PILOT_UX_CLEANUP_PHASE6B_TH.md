# Phase 6B — Pilot UX Cleanup

รอบนี้เน้นเก็บงานหน้าจอให้พร้อมสำหรับการทดสอบกับผู้ใช้จริงมากขึ้น โดยยังไม่เพิ่มฟีเจอร์ใหญ่ใหม่

## สิ่งที่ปรับ

- ปรับข้อความในหน้าลูกค้าให้เป็นภาษาคนใช้งานจริงมากขึ้น
- ลดคำที่เป็นเชิงเทคนิค เช่น prototype, production, dashboard, local cache ในหน้าที่ลูกค้าหรือร้านเห็น
- ปรับข้อความในหลังบ้านร้านค้าให้อ่านง่ายขึ้น เช่น สมาชิก, ของรางวัล, โปรโมชัน, ลิงก์รับแต้ม
- ปรับข้อความในหน้าแอดมินให้เป็นภาษาไทยที่เข้าใจง่ายขึ้น แต่ยังคงข้อมูลตรวจระบบที่จำเป็น
- หน้าแรกปรับ wording ให้เหมาะกับระบบ iM Sticker Loyalty มากขึ้น
- แผง Login with LINE ปรับข้อความให้เป็นมิตรขึ้น และลดคำเทคนิคที่ไม่จำเป็น

## สิ่งที่ยังคงไว้

- ระบบ LINE Login / LIFF ยังเหมือนเดิม
- ระบบ Admin Email Login ยังเหมือนเดิม
- API, schema และ flow บันทึกข้อมูลยังเหมือนเดิม
- หน้า demo ยังอยู่สำหรับทดสอบภายใน

## จุดที่ควรทดสอบหลัง deploy

- `/customer/im-sticker` บนมือถือและใน LINE
- เมนู รางวัล / รับแต้ม / ประวัติ / โปรไฟล์
- `/merchant/im-sticker` โดยเฉพาะแท็บสมาชิก ของรางวัล และลิงก์รับแต้ม
- `/admin` หลัง login ด้วย email/password
- ลิงก์ Rich Menu ที่แสดงใน `/admin`
