# Reward Approval Link Fix — ตรวจลิงก์รับรางวัล

สถานะ: เพิ่มแล้วในแพตช์หลัง Phase 6D

## เป้าหมาย

แก้ flow คำขอแลกรางวัลให้เจ้าของร้านตรวจและอนุมัติจากลิงก์ที่ลูกค้าส่งมาได้เหมือนเดิม

## สิ่งที่เพิ่ม

- เพิ่มช่อง “ตรวจสอบลิงก์รับรางวัลจากลูกค้า” ในหน้า `อนุมัติรางวัล`
- รองรับการวางลิงก์รูปแบบ `/merchant/{shopSlug}?merchantTab=approvals&redeem={transactionId}`
- รองรับการวางเฉพาะรหัสรายการ เช่น `tx_...`
- ถ้าลิงก์ถูกต้อง ระบบเปิด popup รายละเอียดรายการแลกรางวัล
- ใน popup มีปุ่ม `อนุมัติ` และ `ไม่อนุมัติ`
- หลังอนุมัติ/ไม่อนุมัติ popup จะปิด และยังอยู่หน้าอนุมัติรางวัลเหมือนเดิม
- ถ้าลิงก์ไม่ถูกต้อง ระบบเปิด popup แจ้ง “ลิงก์ไม่ถูกต้อง” พร้อมปุ่มปิด
- ถ้าเปิดลิงก์จาก LINE หรือ browser โดยตรง ระบบจะเข้าหน้าอนุมัติรางวัลและเปิด popup ตรวจรายการให้อัตโนมัติ

## หมายเหตุ

แพตช์นี้ไม่ต้องรัน SQL ใหม่ เพราะแก้เฉพาะ frontend flow และ logic ตรวจ query parameter ในหน้า merchant
