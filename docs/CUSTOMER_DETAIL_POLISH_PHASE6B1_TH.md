# Phase 6B.1: Customer App Detail Polish

รอบนี้ปรับรายละเอียดฝั่งลูกค้า `/customer/im-sticker` ให้เหมาะกับการใช้งานผ่าน LINE OA / LIFF มากขึ้น

## สิ่งที่ปรับ

- ลิงก์รับแต้ม `?code=...` จะเปิดหน้ารับแต้มและแสดง popup ยืนยันรับแต้ม
- Popup รับแต้มแสดงชื่อร้านและจำนวนแต้มชัดเจน
- ปุ่มใน popup เปลี่ยนเป็น `ยืนยัน` และ `ไม่รับ`
- เมื่อกดยืนยันรับแต้ม ระบบแสดงข้อความรับแต้มสำเร็จ แล้วพากลับหน้าแรก LIFF `?tab=home`
- เมื่อกดไม่รับ ระบบพากลับหน้าแรก LIFF `?tab=home`
- หน้า “รับแต้ม” เพิ่มปุ่มเปิดกล้องเพื่อสแกน QR Code
- ถ้ากดตรวจรหัสโดยยังไม่ได้กรอก จะแจ้งว่า `กรอกรหัสก่อน`
- เพิ่มกล่องข้อมูลร้านแบบสั้นในหน้าแรก
- เพิ่มกล่องแต้มใกล้หมดอายุใน 30 วัน
- ปรับ empty state ในหน้าประวัติให้อ่านง่ายขึ้น
- เพิ่มข้อมูลสรุปสมาชิกในหน้าโปรไฟล์

## หมายเหตุ

- กล้อง QR ใช้ API ของ browser ถ้าเครื่องหรือ browser ไม่รองรับการอ่าน QR อัตโนมัติ ระบบจะแจ้งให้กรอกรหัสเอง
- จำนวนแต้มใกล้หมดอายุในรอบนี้แสดงเป็น 0 ก่อน เพราะยังไม่มีระบบ point expiry จริงใน database
