# Merchant UI Contrast Fix - Phase 5B.1

รอบนี้แก้เฉพาะปัญหาความชัดเจนของตัวหนังสือในหน้า `/merchant/im-sticker` หลังจาก Phase 5B

## สิ่งที่แก้

- ปรับสีชื่อ/เบอร์โทร/รายละเอียดลูกค้าในแท็บสมาชิก CRM ให้เป็นสีเข้มบนพื้นหลังสว่าง
- ปรับสีหัวตารางและเส้นคั่นรายการลูกค้าให้อ่านง่ายขึ้น
- ปรับช่องค้นหาลูกค้าให้เป็นพื้นขาว ตัวหนังสือสีเข้ม
- ปรับตารางคำร้อง/ประวัติธุรกรรมให้ใช้สีที่เหมาะกับพื้นหลังขาว
- ปรับปุ่ม `เปิด` / `ปิด` ของรางวัลให้เป็นปุ่มพื้นขาว เส้นขอบชัด ตัวหนังสือเข้ม
- ปรับการ์ดของรางวัลให้เป็นพื้นขาวและอ่านง่ายขึ้นในหน้า merchant production view

## วิธีทดสอบ

1. เปิด `/merchant/im-sticker`
2. เข้าแท็บ `สมาชิก CRM`
3. ตรวจชื่อ เบอร์โทร LINE และรายละเอียดลูกค้า
4. เข้าแท็บ `ของรางวัลสะสมแต้ม`
5. ตรวจปุ่ม `เปิด` / `ปิด` ของรางวัล
6. ตรวจแท็บ `อนุมัติแลกรางวัล` และ `ประวัติธุรกรรม`
