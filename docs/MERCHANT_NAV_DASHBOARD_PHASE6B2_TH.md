# Phase 6B.2: Merchant Navigation & Dashboard Cleanup

รอบนี้ปรับหน้า `/merchant/im-sticker` ให้ใช้งานง่ายขึ้นสำหรับเจ้าของร้านบนมือถือ โดยยังใช้ฟีเจอร์เดิมที่มีอยู่ก่อน ไม่เพิ่มระบบใหญ่ใหม่

## สิ่งที่ปรับ

- เพิ่มหน้า `แดชบอร์ด` เป็นหน้าแรกของหลังบ้านร้านค้า
- เปลี่ยนเมนูแท็บด้านบนเดิมให้เป็นปุ่ม `เมนู` แล้วกดเพื่อขยายรายการหน้า
- เพิ่มแถบเมนูล่างบนมือถือ คล้ายหน้าลูกค้า
- หน้าแดชบอร์ดใหม่แสดงภาพรวมร้าน เช่น
  - รางวัลที่รอยืนยัน
  - จำนวนสมาชิก
  - แต้มที่แจกแล้ว
  - ลิงก์รับแต้มที่ยังใช้งานได้
  - รายการล่าสุด
  - ทางลัดไปยังหน้าที่ใช้บ่อย
- เพิ่มหน้า `ตั้งค่า` แบบอ่านข้อมูลเบื้องต้นก่อน เช่น ชื่อร้าน slug อัตราแจกแต้ม และลิงก์หน้าลูกค้า

## เมนูล่างบนมือถือ

เมนูหลักที่แสดงด้านล่างมี 5 รายการ:

1. หน้าแรก
2. รับแต้ม
3. รางวัล
4. อนุมัติ
5. ตั้งค่า

เมนูอื่น ๆ เช่น `สมาชิก` และ `โปรโมชัน` ยังเข้าได้จากปุ่ม `เมนู` ด้านบน เพื่อรองรับการเพิ่มหน้าใหม่ในอนาคต

## หมายเหตุ

รอบนี้เป็นการจัด layout และ navigation ก่อน ยังไม่ได้เปลี่ยน logic การแจกแต้ม แลกรางวัล หรือ sync database
