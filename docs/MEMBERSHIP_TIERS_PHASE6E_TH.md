# Phase 6E — Membership Tiers แบบ Database จริง

เพิ่มระบบระดับสมาชิกแบบผูกกับร้านค้า โดยใช้แต้มสะสมรวมตลอดอายุสมาชิก (`lifetimePoints`) เป็นเกณฑ์อัปเกรดระดับ

## สิ่งที่เพิ่ม

- ตารางใหม่ `membership_tiers`
- ค่าเริ่มต้นต่อร้าน:
  - Member = 0 แต้ม
  - Silver = 500 แต้ม
  - Gold = 1,500 แต้ม
  - Platinum = 3,000 แต้ม
  - VIP = 5,000 แต้ม
- หน้า Merchant → ตั้งค่า → กล่อง “ตั้งค่าระดับสมาชิก”
- เจ้าของร้านแก้แต้มขั้นต่ำ / คำอธิบายสิทธิ์ / เปิด-ปิดระดับได้
- ชื่อระดับล็อกไว้ก่อนใน MVP เพื่อให้ badge และรายงานไม่ปนกัน
- ลูกค้าใหม่เริ่มต้นที่ `Member`
- เมื่อมีการเพิ่มแต้ม ระบบคำนวณ tier ใหม่จากตาราง `membership_tiers`

## วิธีคำนวณ

ระบบเลือกระดับที่:

1. `is_active = true`
2. `min_lifetime_points <= lifetimePoints`
3. ถ้ามีหลายระดับตรงเงื่อนไข จะเลือกระดับที่มี `min_lifetime_points` สูงที่สุด

ตัวอย่าง: ถ้าลูกค้ามี lifetimePoints = 1,700 และร้านใช้ค่าเริ่มต้น ระบบจะให้ระดับ `Gold`

## SQL migration

ต้องรันไฟล์นี้ก่อน deploy code:

```text
neon/migrations/005_phase_6e_membership_tiers.sql
```

ไฟล์นี้จะ:

- ขยาย constraint ของ `customers.tier`
- สร้างตาราง `membership_tiers`
- seed ค่า default tiers ให้ร้านเดิมทุกร้าน
- ปรับลูกค้าเดิมให้ tier ตรงกับแต้มสะสมรวมตามค่า default

## ขอบเขตที่ยังไม่ทำใน Phase นี้

- ยังไม่ทำการลดระดับรายปี
- ยังไม่ให้ร้านแก้ชื่อระดับเอง
- ยังไม่ผูกสิทธิ์พิเศษกับ promotion อัตโนมัติ
